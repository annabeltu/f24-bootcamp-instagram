# Instagram Clone

Description: This Instagram Clone uses Swift and XCode to demonstrate the UI/UX of a post on instagram. By recreating the appearance of an instagram post that may appear on an individual's feed I was able to customize the spacing, likes, comments, and more. This clone was an experimental project to gain experience with Swift and XCode. In the future, I would love to make it more adaptable for the user, so I can create and delete live comments. I would also like to be able to make the like, message, and bookmark features more responsive. 

Features: Something that makes this project stand out is its focus on detail. By replicating the spacing and font of what would show on Instagram itself, the design is almost identical.
